## Users

La aplicación está diseñada principalmente para Eduardo, quien administra las rutas y también
opera entregas desde el teléfono. Se usa tanto en interiores para preparar rutas como en calle,
con atención dividida, conectividad variable y necesidad de resolver acciones con pocos toques.

## Product Purpose

Concentrar en Android las capacidades operativas de Regi Bazar: crear y administrar rutas,
corregir datos de entrega, optimizar paradas, cobrar, documentar entregas, comunicarse y continuar
trabajando cuando la conexión sea inestable. El éxito se mide en menos cambios entre web y móvil,
menos captura repetida y menor tiempo por parada.

## Brand Personality

Directa, cálida y poderosa. La identidad de Regi Bazar debe sentirse femenina y reconocible,
pero la operación siempre tiene prioridad sobre la decoración.

## Anti-references

- Interfaces corporativas azules o verdes que parezcan parte de Grupo PMM.
- Pantallas saturadas de efectos, tarjetas anidadas o animaciones que retrasen una acción.
- Controles pequeños, ambiguos o dependientes únicamente del color.
- Flujos que obliguen a volver al sitio web para completar una tarea cotidiana.

## Design Principles

1. La siguiente acción importante debe estar visible y alcanzable con una mano.
2. La información crítica de una entrega debe poder leerse de un vistazo.
3. Las tareas administrativas deben ser tan rápidas como las del conductor.
4. La aplicación debe degradarse con claridad cuando no hay conexión y recuperarse sola.
5. Toda automatización debe mostrar qué cambió y permitir verificar el resultado.

## Accessibility & Inclusion

Mantener contraste alto, objetivos táctiles de al menos 48 dp, texto legible bajo luz exterior,
descripciones para iconos y retroalimentación que no dependa solo del color. Respetar la preferencia
del sistema para reducir movimiento y evitar animaciones largas en flujos operativos.
